  INSTRUCCIONES DE INSTALACIÓN
═══════════════════════════════════════════════════════════════════════════════

OPCIÓN 1: Windows Environment Variables (Permanente)
───────────────────────────────────────────────────

1. Click derecho en "This PC" → Properties
2. Click "Advanced system settings"
3. Click "Environment Variables"
4. Click "New" en "User variables"
5. Para cada variable arriba:
   - Variable name: OPENCODE_ZEN_API_KEY (ej)
   - Variable value: (tu valor)
   - Click OK

6. Reinicia PowerShell/CMD
7. Verifica con: $env:OPENCODE_ZEN_API_KEY


OPCIÓN 2: Archivo .env (Temporal - para desarrollo)
─────────────────────────────────────────────────

1. Crea archivo: .env en raíz del proyecto
2. Copia todas las variables arriba
3. Llena los valores que faltan
4. Guarda
5. Ejecuta: python -m dotenv


OPCIÓN 3: PowerShell (Por sesión)
───────────────────────────────

$env:OPENCODE_ZEN_API_KEY = "tu_valor"
$env:OPENCODE_GO_API_KEY = "tu_valor"
# ... etc para cada variable
